# Скорость и ограничение

Одностраничное веб-приложение для браузера Tesla: показывает текущую скорость по GPS
и действующее ограничение скорости на текущем участке дороги по данным OpenStreetMap.

**Приложение носит справочный характер.** Оно не заменяет ни штатное распознавание
знаков, ни сами дорожные знаки: приоритет всегда за знаком на дороге.

---

## Как это работает

| Модуль | Ответственность |
|---|---|
| `index.html` | Разметка экрана |
| `app.js` | Точка входа, оркестрация, состояния интерфейса, Wake Lock |
| `geo.js` | `watchPosition`, расчёт и сглаживание скорости |
| `overpass.js` | Запросы к Overpass API, кэш дорог, rate limit, бэкофф |
| `matching.js` | Геометрия (гаверсинус, азимут, проекция), выбор сегмента, гистерезис |
| `maxspeed.js` | Разбор тега `maxspeed`, таблица implicit-ограничений по странам |
| `style.css` | Тёмная высококонтрастная тема |

Бэкенда нет, сборщика нет, npm-зависимостей в рантайме нет, внешние CDN не подключаются.
Используются нативные ES-модули (`<script type="module">`).

### Скорость

Основной источник — `position.coords.speed` (м/с → км/ч умножением на 3.6).
Если `speed` равен `null` или `NaN`, скорость считается по формуле гаверсинуса между
двумя последними фиксами — но только при `0.5 с ≤ dt ≤ 5 с` и точности лучше 50 м.
Если условия не выполнены, прежнее значение сохраняется (ноль не показывается).
Дальше — сглаживание EMA с `alpha = 0.3`; значения ниже 3 км/ч приводятся к нулю,
чтобы подавить дрейф GPS на стоянке.

### Ограничение

Дороги вокруг точки запрашиваются у Overpass API (`way(around:60,…)` по основным типам
`highway`). Из полученных way выбирается сегмент: проекция точки на каждый отрезок,
отсев дальше 40 м, фильтр по совпадению азимута с `coords.heading` (±50°, для `oneway`
только прямое направление; при скорости ниже 10 км/ч или `heading === null` фильтр не
применяется). Кандидаты ранжируются по расстоянию, а при разнице менее 10 м приоритет
получает более высокий класс дороги. Гистерезис в 15 м не даёт знаку «мигать» на
развязках.

Тег `maxspeed` разбирается с поддержкой `50`, `30 mph`, `none`, `walk`, `signals`,
`variable` и префиксов вида `DE:urban`. При отсутствии `maxspeed` проверяются
`maxspeed:forward` / `maxspeed:backward` по выбранному направлению, затем `zone:maxspeed`.
Страна берётся из тегов way или из последней известной привязки — по координатам она
не угадывается, при неизвестной стране показывается «нет данных».

Ограничение, выведенное из таблицы значений по умолчанию, а не из явного тега,
показывается пунктирной окантовкой знака.

### Лимиты запросов

- новый запрос — только при смещении более 150 м либо через 120 с;
- жёсткий минимум между запросами — 5 с, целевой темп — 10 с (это и даёт не более
  60 запросов за 10 минут);
- дополнительно действует жёсткий бюджет: не более 60 запросов в скользящем окне 10 минут;
- ответы кэшируются в памяти: до 500 way, TTL 10 минут, вытеснение по LRU;
- при ошибке сети — индикатор офлайна и повтор с задержкой 5 → 10 → 20 → 40 → 60 с;
- при уходе вкладки в фон запросы приостанавливаются.

Пока новый ответ не пришёл, подбор сегмента продолжается локально по кэшу. Но если
привязка к дороге потеряна или не подтверждалась дольше 30 секунд, ограничение
сбрасывается в «нет данных» — последнее известное значение как актуальное не показывается.

### Приватность

Координаты уходят только в Overpass API и больше никуда. Ни аналитики, ни логирования,
ни сохранения треков. `localStorage` не используется.

## Деплой на GitHub Pages

Geolocation API работает только по HTTPS, поэтому GitHub Pages подходит как есть.

1. Запушьте файлы в репозиторий (ветка `main` или любая другая).
2. **Settings → Pages**: в разделе *Build and deployment* выберите
   *Source: Deploy from a branch*, ветку и папку `/ (root)`.
3. Нажмите **Save** и подождите пару минут, пока пройдёт деплой.
4. Адрес будет вида `https://<username>.github.io/<repo>/`.

Никакой сборки не требуется: репозиторий уже содержит готовые статические файлы.
Файла `.nojekyll` не нужно — имена файлов и папок не начинаются с подчёркивания.

## Как открыть в машине

1. Остановите автомобиль и включите режим «Парковка» — настраивать браузер на ходу нельзя.
2. Откройте меню приложений → **Браузер** (Toybox / значок глобуса, в зависимости от версии ПО).
3. Введите адрес страницы и добавьте её в закладки, чтобы не набирать заново.
4. Нажмите **«Старт»**. Браузер спросит разрешение на доступ к геолокации — разрешите его.
   Автоматически разрешение не запрашивается: браузеры блокируют запрос без действия
   пользователя.
5. После запуска кнопка уменьшается и уходит в угол.

Экран удерживается включённым через Wake Lock API, если браузер его поддерживает;
если нет — приложение работает так же, просто экран может гаснуть по обычным правилам.

Ограничения среды: доступ к данным автомобиля (CAN-шина, штатный спидометр, Tesla Fleet
API) из вкладки браузера невозможен, поэтому скорость берётся исключительно из GPS.

## Отладка на компьютере и телефоне

Приложение одинаково работает на телефоне (портретная раскладка предусмотрена) и в
десктопном Chrome.

Для проверки без движения:

1. Откройте страницу по HTTPS или через `http://localhost` (иначе геолокация недоступна).
   Локально удобно так: `python3 -m http.server 8080`, затем `http://localhost:8080/`.
2. DevTools → **More tools → Sensors** → *Location: Other…* и задайте координаты.
   Например, Франкфурт-на-Майне: `50.1109, 8.6821`.
3. Нажмите «Старт» и меняйте координаты — ограничение будет пересчитываться.

Полезно знать при отладке: в режиме подмены координат Chrome отдаёт `coords.speed === null`
и `heading === null`. Это штатный сценарий — скорость в этом случае считается по
гаверсинусу между фиксами, а фильтр по направлению не применяется.

## Тесты

Стенд лежит в папке `tests/` со своим `package.json`, чтобы у самого приложения
зависимостей по-прежнему не было. Подробности — в [`tests/README.md`](tests/README.md).

```bash
cd tests
npm ci && npx playwright install chromium
npm test
```

- `npm run test:unit` — модульные тесты геометрии, разбора `maxspeed`, расчёта
  скорости и кэша. Работают на голом `node --test`, без установки зависимостей.
- `npm run test:e2e` — браузерные тесты в Chromium: подменяются только
  `navigator.geolocation` и `fetch` к Overpass, остальное — настоящий код.
  Прогоняются в двух раскладках: экран машины 1200×800 и телефон 412×915.

Проверяются все критерии приёмки из ТЗ, включая ограничение в 60 запросов к
Overpass за 10 минут движения (прогоняется на поддельных часах) и отсутствие
ошибок страницы в любом сценарии.

## Что не входит в объём

Прокладка маршрута, карта и история поездок; динамические ограничения (табло переменной
информации, ограничения по погоде) — их нет в OSM; ограничения для отдельных типов ТС
(грузовики, прицепы).
